BLACKLINE BARBER — Dossier images
=================================

Ce dossier contient les visuels SVG utilisés par le site
(hero.svg, apropos.svg, galerie-1.svg à galerie-6.svg).

Ces images sont des placeholders premium cohérents avec
l'identité visuelle du site, afin que le projet fonctionne
hors ligne dès l'ouverture de index.html.

POUR LES REMPLACER PAR DE VRAIES PHOTOS :
1. Placez vos photos dans ce dossier (images/),
   par exemple coupe-1.jpg, salon.jpg, etc.
2. Dans index.html, remplacez le src des balises <img>
   par le nom de votre fichier : images/votre-photo.jpg
3. Adaptez l'attribut alt pour décrire chaque photo.

Conseil : des photos au format vertical (4:5) donnent le
meilleur rendu dans la galerie.
